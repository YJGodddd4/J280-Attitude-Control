# 一、 FPGA的基本组成
1. 逻辑块：也称为可配置/可编程逻辑块（CLB），包括：LUT查找表，FF触发器和其他原件
2. 互连：可编程互联网络（导线和可编程开关组成的网络），用于连接逻辑块与逻辑块之间，逻辑块与I/O块之间
3. I/O块：负责将FPGA与外部设备和信号连接起来，将内部逻辑引脚接到外部芯片引脚，实现与其他组件的通信

因此FPGA可自由配置硬件，五固定架构。
4. 硬件描述语言Verilog：设计定义FPGA逻辑块和互连
5. 比特流生成和配置： 综合设计随后被转换为配置比特流，这是一个二进制文件，包含配置 FPGA 逻辑块、互连和 I/O 块所需的数据。这一过程被称为 "放置-布线"，包括将设计的逻辑元素映射到 FPGA 的物理资源，并确定互连的布线路径。由此产生的位流通过专用编程接口或外部存储设备加载到 FPGA 的配置存储器中。加载位流后，FPGA 的内部连接和逻辑将根据指定的设计进行配置，使器件能够执行所需的功能

# 二、 MCU的基本组成
1. 中央处理器CPU:CPU 是微控制器的核心，负责执行程序存储器中存储的指令。它处理数据并控制微控制器外设的运行（顺序执行）。
中央处理器的架构（如哈佛或冯-诺依曼）和指令集（如 RISC 或 CISC）会对其性能和能效产生重大影响。一些常见的微控制器 CPU 架构包括 ARM Cortex、AVR 和 PIC。
2. 存储器：微控制器中的内存用于存储程序代码和运行所需的数据。内存主要有两种类型：程序内存和数据内存。程序存储器通常采用非易失性闪存，用于存储CPU执行的指令。数据存储器通常采用易失性SRAM（Static Random Access Memory），用于存储程序执行过程中使用的变量和临时数据。微控制器内存的大小和类型会影响其性能、功耗以及对特定应用的适用性。
3. 外设：外设是集成到微控制器中的附加组件，可提供特定功能。其中包括通信接口（如 UART、SPI 和 I2C）、定时器、计数器、脉宽调制 (PWM) 发生器、模数转换器 (ADC) 和数模转换器 (DAC)。外设使微控制器能够与外部设备交互并执行各种任务，如读取传感器数据、控制执行器或与系统中的其他组件通信。微控制器中外设的可用性和功能会对其在特定应用中的适用性和易用性产生重大影响。

# 三、两者区别
FPGA 擅长并行处理任务但功耗大，具有灵活性；而微控制器则针对顺序处理进行了优化，功耗小，具有定制化的特点。高性能多线并行处理用FPGA，顺序处理用MCU（低功耗，编程简单）
