LUT4：4输入查找表。可以把 LUT4 想成一个：
输入最多四个变量，根据输入组合直接给出结果的小型可编程逻辑盒子。执行的逻辑可以有多个：AND

XOR
比较

MUX等
复杂组合逻辑

REG/FF：寄存器和触发器，寄东西以便使用

CFU 和 CLU：
| 功能 | CLU | CFU |
|---|---|---|
| LUT | ✓ | ✓ |
| 算术逻辑 | ✓ | ✓ |
| ROM | ✓ | ✓ |
| 静态 RAM | × | ✓ |

CRU可编程布线单元：构成内部连接网络，连接 CFU、IOB 等资源，而布线资源由高云 FPGA 软件自动生成。

Carry Chain快速进位链：如果做一个 32 位加法器，普通方法可能需要很多 LUT 之间绕来绕去。
有专用 Carry Chain 后：
bit0 → bit1 → bit2 → bit3 → ...进位可以沿专用线路高速传递

因为对于你现在的 J280 姿态控制系统，真正第一阶段会频繁碰到的是 LUT/FF、时钟、GPIO、Bank、管脚约束和 PWM。 等这些打通了，再去学 ADC、编码器、PID、DSP，你会顺很多。

# 二、J280系统硬件结构（拓展版）
J280姿态控制系统整体采用：

**核心板 + 底板（拓展板）**

的结构。
其中：
- 核心板主要负责 FPGA 运算、数据存储、时钟、下载以及通信
- 底板主要负责 ADC采集、电机驱动、编码器采集、角位移传感器以及接口扩展
整个系统可以简单理解为：

                    J280姿态控制系统
                           │
              ┌────────────┴────────────┐
              │                         │
           核心板                      底板
              │                         │
        GW2A-55 FPGA              ADC / 电机驱动
              │                  编码器 / 角度传感器
              │                         │
              └───────────┬─────────────┘
                          │
                       姿态控制

![alt text](image-2.png)

## 1. FPGA如何产生控制信号

FPGA通过Verilog逻辑产生PWM和方向控制信号，再通过IOB和物理管脚输出到外部电路。

FPGA内部逻辑
    ->
CRU布线
     ->
IOB
     ->
物理管脚
     ->
TB6612
     ->
电机

## 2. FPGA如何读取反馈信号

J280主要通过角位移传感器和编码器获取系统状态。
- 角度反馈:
摆杆角度
     ->
角位移传感器
     ->
模拟电压
     ->
ADC
     ->
10bit数字量
     ->
FPGA

- 电机反馈
电机旋转
     ->
编码器
     ->
A相 / B相
     ->
FPGA

FPGA可以根据编码器信号判断：
- 电机转速
- 旋转方向
- 转动位置变化
## 3. 最终将输入反馈和输出控制结合：
输入反馈
   ->
FPGA计算
     ->
输出控制
    ->
电机运动
    ->
系统状态变化
     ->
重新反馈

因此，J280姿态控制系统的核心可以概括为：
检测状态 → FPGA计算 → 控制电机 → 状态变化 → 再次检测
