# 1.什么是PID控制算法？
PID控制算法是一种基于反馈的控制策略，通过计算期望值与实际值之间的误差，并对误差进行比例（P）、积分（I）、微分（D）三种数学运算，输出控制信号来调节被控对象。

数学表达式为：
u(t) = Kp × e(t) + Ki × ∫e(t)dt + Kd × de(t)/dt

其中：
u(t)：控制器输出,
e(t)：误差信号（设定值 - 实际值）,
- Kp：比例增益,根据当前误差的大小产生控制作用，误差越大，控制作用越强。它能够快速响应误差变化，但单独使用可能产生稳态误差。
- Ki：积分增益,根据误差的累积值产生控制作用，能够消除稳态误差，但可能导致系统响应变慢或产生超调。
- Kd：微分增益,根据误差的变化率产生控制作用，能够预测误差的变化趋势，改善系统的动态性能，减少超调和震荡。
